# portscanner

一个用 Python 写的端口扫描器（学习项目）。

## 用法

    python3 scan.py <目标IP>

例子：

    python3 scan.py 192.168.75.128

输出：

    22 开放
    80 开放

## 原理

对每个端口尝试建立 TCP 连接：

- 返回 0    → 端口开放
- 返回 111  → 端口关闭（对方回 RST）
- 返回 110  → 超时（被防火墙过滤）
- 返回 113  → 主机不可达
